# 文种辨析与公文用语

依据《党政机关公文处理工作条例》（2012）第八条，法定文种共 15 个。审校时先判断文种选择是否正确，再查用语。文种用错属于结构性错误，应在结论中置顶提示。

## 一、15 个法定文种速查

| 文种 | 适用情形 | 行文方向 |
|---|---|---|
| 决议 | 会议讨论通过的重大决策事项 | 下行 |
| 决定 | 重要事项作出安排、奖惩、变更或撤销下级事项 | 下行 |
| 命令（令） | 公布法规、宣布重大强制措施、嘉奖（限法定机关） | 下行 |
| 公报 | 公布重要决定或重大事项 | 公开 |
| 公告 | 向国内外宣布重要或法定事项 | 公开 |
| 通告 | 在一定范围内公布应遵守或周知的事项 | 公开 |
| 意见 | 对重要问题提出见解和处理办法 | 上行/下行/平行 |
| 通知 | 发布、传达要求下级执行或周知事项；批转、转发、印发 | 下行为主 |
| 通报 | 表彰先进、批评错误、传达重要精神或情况 | 下行 |
| 报告 | 向上级汇报工作、反映情况、回复询问 | 上行 |
| 请示 | 向上级请求指示、批准 | 上行 |
| 批复 | 答复下级请示 | 下行 |
| 议案 | 各级政府按法律程序向同级人大或常委会提请审议事项 | 特定 |
| 函 | 不相隶属机关之间商洽工作、询问和答复问题、请求批准 | 平行 |
| 纪要 | 记载会议主要情况和议定事项 | — |

## 二、高频混淆对照

- **请示 vs 报告**：请示需上级批复，一事一文，事前行文；报告不需批复，可一文多事，事中事后行文。**"请示报告"混用是 A 类错误**。请示不得夹带报告事项。
- **函 vs 请示**：向不相隶属机关（含同级、下级职能部门）请求批准用函，不用请示。误把函当请示"抬高对方"或把请示当函"矮化上级"都算文种错误。
- **公告 vs 通告**：公告面向国内外、事项重大或法定；通告限一定范围、偏周知执行。部门内部事务或社会影响有限的通告事项用公告属升格。
- **通知 vs 通报**：通知布置工作、周知事项；通报重在表彰、批评、传精神，靠典型性发挥作用。发文件用"印发通知"，不用"印发通报"。
- **决定 vs 通报（奖惩）**：重大奖惩用决定；一般性表彰批评、带教育意义的用通报。
- **意见 vs 通知**：意见重在提出见解和处理办法，留有执行弹性；通知重在明确执行要求。
- **批复 vs 函（答复）**：答复下级请示用批复；答复不相隶属机关询问用函。

## 三、结构用语惯例（编辑参照，非强制条款）

- **开头**：通知常用"为了……根据……现将……通知如下"；函常用"贵单位/贵局……现函告如下"；请示常用"为了……（理由），现请示如下"。
- **引叙**：批复、复函引述来文用"你单位《……》（X字〔20XX〕X号）收悉"。
- **经办**：拟（打算）、兹（现在）、业经/已经、责成（指定办理）、敦请/恳请（视行文方向）、核查、照办。
- **结尾分文种**：
  - 请示："妥否，请批示""特此请示，请予批准"
  - 报告："特此报告"（**不得写"请批示"**，报告不需批复）
  - 通知："特此通知"
  - 函："特此函告""特此函复""盼复""请予支持为荷"
  - 批复："此复"
- **称谓**：下级对上级自称"我"（我局、我会）；对不相隶属或平级称"贵"（贵局）；上级对下级称"你"（你单位）。不得自称"本公司""咱们单位"等口语。
- **引文层级**：先引标题后引文号："《……》（X发〔20XX〕X号）"。

## 四、审校红线

- 文种与行文方向不符（如向下级"请示"）→ A 类。
- 报告中出现请示性内容或"请批示"结尾 → A 类。
- "请示报告""告示"等非法文种名 → A 类。
- 结尾用语与文种错配（请示写"特此函告"）→ A 类。
- 用语口语化（"麻烦你们""搞一下""尽快搞定"）→ B/C 类按语境。
- 语气越权（平级机关用"必须""责令"）→ A 类，改为商洽语气。

## 五、函件收束语写法（编辑参照，实务通行）

| 写法 | 规则 |
|---|---|
| 此致 | 正文末单独成段；左空二字；**不加任何标点** |
| 敬礼！ | 另起一行**顶格**；用中文感叹号 |
| 顺颂商祺/时祺 | 可一行，也可拆两行（"顺颂"+"商祺！"）；标点可有可无，全篇统一 |
| 特此函告/特此函复/盼复 | 函件结尾，不换行顶格 |

常见错误（A 类）：「此致敬礼」连排一行；「此致」带句号；「敬礼」无叹号或写成"敬礼。"；此致与敬礼之间空行。普通公文结尾「特此通知」「特此报告」直接接正文段，不空行。
