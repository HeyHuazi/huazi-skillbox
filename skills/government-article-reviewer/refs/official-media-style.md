# 主流官方媒体成稿参照

本文件用于审核和修订公开发布的政务信息稿、会议报道、领导活动稿、部门发布会消息。它总结的是新华社、新华网、央视网等已发布稿件中反复出现的编辑方法，不是国家标准，也不是所有单位必须照抄的固定模板。

## 一、样本与使用方法

本轮抽样以2026年7月31日公开页面为主，包括：

- 央视网《国家能源局：今年迎峰度夏 全国电力供应总体平稳》
- 央视网《国家发展改革委：共建“一带一路”取得扎实进展》
- 央视网《今年7550亿元中央预算内投资已基本下达完毕》
- 央视新闻《广州新机场等开建 109项重大工程加快实施》
- 新华网《河北省委主要负责同志职务调整 罗文任河北省委书记》
- 新华社重要会议报道《习近平在中共中央政治局第二十七次集体学习时强调……》

使用时先判断稿件类型，再选相近样本的结构特点。不得把中央领导活动报道的特殊格式套到普通部门动态，也不得因为媒体稿件采用某种写法，就把其他合规写法判为错误。

## 二、共同写法

### 1. 标题先给核心事实

常见结构：

- `发布主体：核心结论`
- `关键数字 + 事项 + 进展`
- `机构或职务调整事项 + 结果`
- 重要领导活动稿使用`人物 + 场景 + 强调 + 核心要求`

标题通常省去“关于、认真、全面、圆满、进一步”等弱信息词，把最值得读者知道的结果放进去。标题里的结论必须被正文直接支撑。

审核时重点问：

- 标题是否提供了具体事实，而不只是“某某会议顺利召开”？
- 主体、事项、结果是否清楚？
- 标题是否比正文说得更大、更满？
- 数字标题是否注明或可从正文追溯统计口径？

### 2. 导语快速回答发生了什么

普通发布会和部门消息常在第一句交代：

`日期 + 发布主体/会议 + 信息来源 + 核心结论`

例如不是先写背景意义，而是先说明某部门何时召开发布会、谁介绍了什么、最重要的结果是什么。

会议活动稿通常先交代：

`时间 + 主体 + 活动/会议 + 主持或出席者 + 核心讲话/决定`

导语不必机械塞满五要素。地点、参与人员或背景如果不是理解核心事实所必需，可以放后文。公开稿件应优先让读者在首段知道“发生了什么”。

### 3. 每段承担一个信息任务

常见段落顺序：

- 第一段：事件和核心结论
- 第二段：来源身份与关键数据、措施或事实展开
- 第三段：背景、分类说明或下一步安排

短稿可能只有一至两段。信息少时不要为了“像大稿”硬凑段落和表态。

段内常用分类词组织密集信息，如“经贸合作方面”“互联互通方面”“在抢险救灾方面”“在以工代赈方面”。分类词后必须跟具体事实，不能只跟抽象要求。

### 4. 观点和数据都有归属

成熟稿件会明确区分：

- 媒体或发布单位陈述的事实
- 新闻发言人、负责人、领导作出的判断
- 文件、会议或部门提出的要求
- 记者观察或背景材料

常见归属动词：

- 表示、介绍、指出、强调、称、宣布
- 会议指出、会议强调、会议要求
- 数据显示、据悉、根据……

不要连续数段用“他表示”而让读者找不到主语。首次出现一般写完整职务和姓名，后文在不会混淆时使用姓名。

### 5. 先事实，后评价

“取得扎实进展”“总体平稳”“综合效能”等判断，通常紧邻发布主体或发言人，并由数据、项目、行动支撑。编辑时不要把来源的判断悄悄改成作者或发布单位自己的结论。

弱稿常见问题：先写“成果显著、亮点纷呈、群众满意”，后面没有证据。修订时应改成：

1. 给出项目、数据、措施、时间节点；
2. 明确评价是谁作出的；
3. 缺少依据时降低措辞或删除评价。

### 6. 数字与事实放在同一句或相邻句

成熟短稿常把数字与对象、时间和比较关系绑定：

- `上半年 + 指标 + 达到X + 同比增长Y`
- `已下达X批 + 合计Y元 + 支持何事`
- `实施项目X个 + 带动人数Y + 人均增收Z`

审核数字时不能只查数字格式，还要检查：

- 时间范围
- 统计对象
- 单位
- “达到/增长”“提高到/提高了”的关系
- 同比、环比或累计口径
- 概数与精确数是否冲突

### 7. 人员称谓服从稿件类型

普通部门发布会：首次常用`机构 + 职务 + 姓名`，后文用姓名加“介绍/表示”。

干部任免消息：新华社样本使用“某某同志”，并准确列出“任”“不再担任”等职务变化。这里的“同志”是特定稿件口径，不能推导为所有政务稿都应给人名加“同志”。

重要中央领导活动稿：标题、导语、讲话层级和固定政治表述有高度特殊性，必须以新华社、中国政府网等最新权威原文为准，不自行仿写或改写关键表述。

### 8. 下一步安排写动作，不写态度堆叠

较好的“下一步”包含明确主体和动作，例如：

- 加强监测预警
- 优化资源配置
- 加快项目前期工作
- 争取尽早开工建设

较弱写法是连续堆叠“进一步提高认识、切实增强责任感、全面抓好贯彻落实”。若无法落到动作、对象、期限或结果，应建议压缩。

## 三、按稿件类型检查

### A. 部门发布会短稿

推荐骨架：

1. 日期、部门、发布会名称
2. 发言人给出的核心结论
3. 发言人完整身份与姓名
4. 分项数据、项目或措施
5. 必要时补充下一步安排

审核重点：标题结论是否来自发布会；数据是否保持原口径；“新闻发言人表示”后是否及时给出具体姓名和完整职务。

### B. 工作动态与项目推进稿

推荐骨架：

1. 何时、何单位完成或推进何事
2. 采取了哪些具体动作
3. 形成什么可核验结果
4. 下一步由谁做什么

避免把参会名单、领导表态和背景意义全部挤在首段。若标题只是“某某会议召开”，应判断是否能用会议解决的事项或形成的决定替代空标题。

### C. 会议和领导活动稿

推荐骨架：

1. 时间、会议、主持或出席、核心议题
2. 会议听取或审议的事项
3. `会议指出/强调/要求`分层呈现判断与任务
4. 参会人员与其他信息按重要性后置

“指出、强调、要求”不是随意升级的同义词。无法确认原始讲话层级时，保留原稿并列入核验清单。

### D. 干部职务信息

只依据正式权威发布审核。重点检查：

- “任”“不再担任”“免去”“另有任用”等词是否与原文一致
- 委员、常委、书记等职务是否完整、顺序是否一致
- “同志”称谓是否符合该类权威稿件
- 简历时间、机构历史名称和中央委员等身份是否准确

不得依据新闻风格自行推断任免性质。

## 四、编辑判断

将问题分成三种来源：

- **规范错误**：国家标准、法规、明确语法或事实一致性问题，可列A类。
- **媒体成稿偏差**：导语慢、标题空、信息归属模糊、段落臃肿，可列C类；若导致事实责任主体不清，可升A或B。
- **单位口径差异**：同志称谓、职务顺序、固定栏目格式等，列B类核验，不因媒体样本不同就直接判错。

给修改建议时说明“参考新华社/央视等公开稿件的常见编辑方式”，不要写成“国家规定必须如此”。

## 五、不应照搬的部分

- 不照搬“电头”、记者署名和媒体来源标识，除非稿件本身属于新闻机构发布。
- 不把中央领导活动稿的长标题和固定政治表述用于普通地方工作动态。
- 不为了像新闻而删掉正式公文必需的主送机关、文种结构和附件信息。
- 不复制样本中的具体政治表述、数字、项目和评价到其他稿件。
- 不将当天单篇稿件中的编辑选择上升为普遍硬规则。
